# Forge a Nation — V7.10

Hero background updated to a Landscape — Night-inspired procedural Three.js scene: moonlit terrain, dense star field, fog, stones, grass, distant ridges, settlement lights, and subtle camera motion.

The existing progression-based 3D city renderer is preserved.

This is an original implementation inspired by the publicly described ThreeUI Landscape — Night visual direction; it does not bundle ThreeUI proprietary source/assets.
